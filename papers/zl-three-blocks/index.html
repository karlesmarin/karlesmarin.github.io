Why three blocks? The limited augmented Zarankiewicz number in fixed width

Carles Marín Muñoz

Abstract

The limited augmented Zarankiewicz number z_L(m,n) of Qi, Cui and Xu bounds the maximum sum-of-squares rank of m× n biquadratic forms from below: it counts the cells of a maximum C₄-free set in the m× n grid together with pairs of further cells that avoid two forbidden patterns. We determine z_L(m,3)=⌊3m/2⌋+2 for every m≥3, answering a question of Qi, Löfberg and Chen, with a proof formalized in Lean; it also shows that the gap to their weak variant grows like m/6. For a fixed number n of columns we prove that each new row adds ρₙ pairs up to a bounded error, where ρₙ is a rational number given by finitely many linear programs, and that the error is eventually periodic. Pairs placed around a hollow triangle of three column blocks give ρₙ≥λₙ=n/3−1/2+O(1/n); balanced blocks are optimal within this family, and ρₙ=λₙ for n≤6 by rational dual certificates checked in exact arithmetic; we conjecture equality for all n. Consequently, in every fixed width the original criterion stays linearly below the recursive-line, signed and second-order ones. We also reduce Lebedev's canonical base to a graph parameter whose sharp bound is due to Hof, which gives its slope ⌊(n−1)²/4⌋/(n−1) for every n; we find the exact value of z_L(m,4) for every m≥6 by certified computation, fourteen new exact values by exhaustive computer search (eight of them instances of the three- and four-column formulas), and a three-dimensional analogue in which the naive bound of one quarter fails already in 3×3×5, the smallest such box. The admissibility lemmas behind the constructions are formalized in Isabelle/HOL.

Version 2. Changes from version 1: the sharp bound on the graph parameter in Theorem D is due to Hof (2016, Thm. 7.2; Hof, Kern, Kurz and Paulusma, SAGT 2018), and the theorem's contribution is the reduction to it; the integer program over row types is exact for n ≤ 4 only, and no value of the table rests on it for n ≥ 5 (the supplement's program now refuses n ≥ 5); eight of the fourteen new values are instances of Theorems A and E; in Question 1, three-block shadows attain the optimal value for n ≤ 6, which is not a classification of the optimal programs.
